## Audio DSP

**[Mix-Suite](https://github.com/Phantom-FX89/Mix-Suite)** — Modular C++/JUCE mixing suite. Shared DSP core across plugin and standalone targets, benchmark harness, and preset system.

**[TubePreamp](https://github.com/Phantom-FX89/TubePreamp)** — Tube microphone preamp emulation for macOS, shipping as AU and VST3. Three switchable console EQ curves modelled on the SSL 4000, Neve 1073, and Focusrite ISA.

Also in progress privately: a ten-band dynamic EQ (JUCE 8 / C++20) and a modular channel-strip host built on a shared DSP core.
